# Reproducibility evidence

To substantiate the supplied manuscript's experimental claims, obtain:

1. The authentic renderer and evaluation implementation used for the reported runs, with commit identifiers and dependencies.
2. Dataset manifest, reference renders, semantic oracles, random seeds and validation/test split identifiers.
3. The validation threshold-tuning log and all selected parameters.
4. Per-instance test labels, predictions and confusion counts for all compared methods.
5. Hardware, software and timing protocol for the reported latency.
6. Scripts regenerating all result tables and Figure 9 from raw test outputs.
7. Separate learned-model training and real-device evaluations if those claims are added.

Archive future runs with timestamps and source versions. Do not describe newly generated measurements as a reproduction of an earlier run without matching source artifacts and protocol.
